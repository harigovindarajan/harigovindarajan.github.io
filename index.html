01
Multi-agent E2E test system Invenco · production
A four-agent feedback loop on Claude Code — Domain Expert, Test Writer, Reviewer, Feedback — writing, reviewing and improving E2E tests across nine microservices. It self-improves on every test run: each result feeds back as context, so the next spec it writes is better than the last.
Alongside it: PR review agents that assess coverage in a fresh session before human review, and Aria-based semantic snapshots replacing brittle screenshot tests — seven assertions collapsed into one comparison.
80% faster authoring ~20% → 95–98% reliability 20–30 min → ~5 min run time

02
Tier-based test strategy Invenco · practice
AI took the dev team to roughly 4× velocity, and testing was about to become the bottleneck. So I rebuilt the strategy around business impact instead of coverage: Tier 1–3 tiers decide what gets tested, how deep, and what can ship without a gate. It removed the single-person manual-testing bottleneck and made confident production deploys routine.
4× dev velocity absorbed 0 manual gatekeepers Black Friday deployed with confidence
